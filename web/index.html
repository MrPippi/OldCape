怎麼穿上？

  1. 在披風頁按「下載遊戲貼圖」，取得 64×32 的 PNG。
  2. 安裝免費的 SkinMC 模組（Fabric 或 NeoForge）。
  3. 到 skinmc.net 註冊並連結你的 Minecraft 帳號，在「Account → SkinMC Capes」上傳這張 PNG 並套用。
  4. 進入遊戲，按 F5 切換視角看看背後。

註：只有同樣裝了 SkinMC 的玩家看得到。只想自己看的話，可以用 Fabric 模組 Client Capes，把 PNG 放進它的設定資料夾就好。正版官方披風無法自訂；OptiFine 只能用旗幟圖案設計，不能使用這張圖。

關於老披風

「台灣麥塊」曾是台灣最大型的 Minecraft 伺服器，玩家可以上傳自己畫的披風。伺服器熄燈後，留下了這三萬件作品。這裡把它們一件件還原成遊戲貼圖，讓老玩家找回自己的那件，也讓大家再看一次當年的創作。
