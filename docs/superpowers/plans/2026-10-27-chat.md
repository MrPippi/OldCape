# 老披風聊天室 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the guestbook dialog with a real-time chat (floating launcher, Durable Object WebSocket room, full history in D1, one Turnstile check per 6 h).

**Spec:** `docs/superpowers/specs/2026-10-27-chat-design.md` (builds on `2026-10-27-guestbook-design.md`).

## Global Constraints

- One room (`idFromName("lobby")`), WebSocket Hibernation API; online = open sockets.
- Rate: 1 message / 3 s, 200 / day per source hash. Session pass: HMAC-SHA256 (`SESSION_KEY`), 6 h.
- Reading needs no session; `say` without a valid session → `error need_session`.
- History: `GET /api/guestbook?before=` (newest first) and `?after=` (oldest first, gap fill after reconnect).
- `POST /api/guestbook` is retired (405); speaking happens over the socket.
- Reports that hide a message broadcast `hidden { id }`.
- No chat code or connection before the launcher is used; the online badge is one `GET /api/chat/online` after load.
- Texts, nickname memory, `#id` cape links, report confirm, and error copy carry over from the guestbook.

## Review Focus

- Socket drops mid-conversation → 「重新連線中…」, backoff reconnect, gap fill, no duplicates.
- Expired session while typing → message kept, Turnstile shown, sent after verification.
- Reader scrolled up when a message arrives → stays put, 「有新訊息」 pill.
- Loading older history keeps the reader's place (no jump).
- Launcher never covers the detail sheet's buttons on phones.

### Task 1: Worker — sessions, rate limits, after-cursor, retire POST

### Task 2: Worker — `ChatRoom` Durable Object

### Task 3: Client data layer
`src/data/guestbook-api.ts` (`list({before|after})`, `session(token)`), `src/data/chat-socket.ts` (reconnect with backoff, injectable WebSocket and timers).

### Task 4: Chat panel + launcher
`src/ui/chat-panel.ts`, `src/ui/chat-message.ts`, `src/ui/chat-launcher.ts`, `src/styles/chat.css`; remove the guestbook dialog, menu item and `guestbook.ts`; `/#guestbook` and `/#chat` open the chat. E2E with a fake WebSocket server via `page.routeWebSocket`.

### Task 5: Deploy
`SESSION_KEY` secret, push, live checks (online count, read-only socket hello, session rejects a bad token).
