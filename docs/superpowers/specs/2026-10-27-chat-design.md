# 老披風聊天室 設計（取代留言板）

日期：2026-10-27
狀態：待使用者確認

## 為什麼要做

留言板是「留下一句話就走」，聊天室則讓同時在逛的老玩家可以當場聊起來，例如「欸你也是 2012 年的嗎？」。這更接近當年伺服器裡的氣氛。

## 使用者已決定的事

- 真正即時：訊息一送出，所有人馬上看到，並顯示在線人數。
- 位置：右下角懸浮按鈕，點開是聊天面板，可以邊逛披風邊聊；手機上打開是全螢幕。
- 保留全部紀錄，可以往上捲看舊訊息。現有的留言會成為聊天紀錄的開頭。
- 防機器人：第一次要發言時通過一次 Turnstile，之後幾小時內可以自由聊天。

## 沿用留言板的部分

暱稱（瀏覽器記住）、300 字上限、`#1234` 變成連結並帶披風小圖、檢舉（3 人檢舉就隱藏）、擋網址和關鍵字、IP 只存雜湊、D1 資料庫和管理 SQL。

## 使用者看到的樣子

- 右下角一個圓形聊天按鈕（Font Awesome 的 comments 圖示），旁邊有小標籤顯示在線人數，例如「3」。
- 點開後：
  - **電腦**：右下角浮出 360×520 的面板，不遮住整個頁面，可以繼續點披風。
  - **手機**：全螢幕，頂部有關閉鈕。
- 面板由上到下：
  - **標題列**：「聊天室 · 3 人在線」和關閉按鈕。
  - **訊息區**：舊的在上、新的在下。打開時捲到最底；往上捲到頂會自動載入更早的訊息。如果你正在看舊訊息時有人發言，底部會出現「有新訊息 ↓」的提示，不會把你拉走。
  - **輸入區**：暱稱，以及一個「單行可延伸」的輸入框。Enter 送出，Shift+Enter 換行。
- 第一次按送出時，輸入區上方出現 Turnstile 驗證；通過後訊息自動送出，之後 6 小時內不用再驗證。
- **不用驗證也能看**：任何人打開聊天室都能即時看到對話，只有發言才需要驗證。
- 斷線時，標題列顯示「重新連線中…」並自動重連；重連後會補抓斷線期間漏掉的訊息。
- 上方選單的「留言板」拿掉，改由懸浮按鈕進入。舊連結 `/#guestbook` 會直接打開聊天室。

## 發言限制

- 每 3 秒最多 1 則、每天最多 200 則，以來源雜湊計算。
- 驗證過的「聊天通行證」有效 6 小時，過期後再驗證一次。
- 被檢舉隱藏的訊息，會即時從所有人的畫面上消失。

## 技術做法

- **即時連線**：Cloudflare Durable Object `ChatRoom`，全站只有一個房間。
  - 使用 WebSocket Hibernation API：沒有人發言時不計費。
  - 在線人數就是目前的連線數。
- **資料**：訊息仍存在 D1 的 `messages` 表，現有的留言就是聊天紀錄的開頭，管理 SQL 不變。
- **API**：
  - `GET /api/guestbook?before=`：沿用，用來往上載入舊訊息。
  - `GET /api/guestbook?after=`：新增，重連後補抓漏掉的訊息。
  - `POST /api/chat/session`：送 Turnstile token，換一張 6 小時的通行證（HMAC 簽章，密鑰是新的 secret `SESSION_KEY`）。
  - `GET /api/chat`：WebSocket 升級。帶通行證就可以發言，沒帶就只能看。
  - 檢舉沿用 `POST /api/guestbook/:id/report`；隱藏時會通知 `ChatRoom` 廣播。
  - 舊的 `POST /api/guestbook`（發留言）移除，改成在 WebSocket 裡發言。
- **WebSocket 訊息格式（JSON）**：
  - 用戶端送出：`say { nickname, body, nonce }`
  - 伺服器送出：
    - `hello { online, canSpeak }`
    - `message { message, nonce? }`
    - `online { count }`
    - `hidden { id }`
    - `error { code, retryAfter?, nonce? }`
- **費用**：Durable Objects（SQLite 版）、Workers、D1、Turnstile 都在免費額度內。WebSocket 休眠可以把計費時間降到最低。
- **測試**：
  - Worker 端用 `@cloudflare/vitest-pool-workers` 測 Durable Object、WebSocket、通行證。
  - 前端用 jsdom 測聊天面板，搭配假的 WebSocket。
  - Playwright 端對端測試搭配假的 WebSocket 伺服器和 Turnstile。

## 不做的事

- 私訊、多個房間、表情回應、圖片、輸入中提示。
- 帳號登入。

## 失敗的樣子（要避免）

- 被洗版卻擋不住。發言頻率限制和檢舉必須在第一版就能用。
- 懸浮按鈕擋到披風牆或下載按鈕。
- 連線斷掉後畫面停住，卻沒有任何提示。
- 首頁變慢：聊天室的程式和連線在按下按鈕前都不載入。在線人數的小標籤需要一個輕量請求，等頁面載入完成後才發送。
