# 老披風留言板 設計

日期：2026-10-27
狀態：使用者已確認方向（2026-10-27），管理頁延後

## 為什麼要做

老披風是一間典藏館，但目前只能看，不能說話。留言板讓老玩家留下當年的回憶，例如「我是當年某某公會的」或「#1234 是我的披風」。這些故事會讓典藏館有人的溫度。

## 使用者已決定的事

- 整個網站只有一個留言板，不做每件披風各自的留言。
- 留言直接公開，事後再管理。
- 不需要登入，填暱稱就能留言。

## 目標

- 手機上 30 秒內就能留下一則留言。
- 不需要帳號、不使用 Cookie 追蹤，延續網站「不追蹤個人」的承諾。
- 垃圾留言和洗版要擋得住，或至少能很快清掉。
- 不影響首頁載入速度：留言板打開時才載入。

## 不做的事

- 不做帳號、登入、個人頁。
- 不做回覆串（巢狀留言）、按讚、圖片上傳。
- 不做即時推播（WebSocket）。

## 失敗的樣子（要避免）

- 被廣告或惡意內容洗版，卻沒有辦法快速刪除。
- 留言框拖慢首頁。
- 收集或外洩留言者的 IP 等個人資料。

## 使用者看到的樣子

- 上方選單在「關於」旁邊新增「留言板」，點了會打開跟「怎麼穿上」「關於」同款的對話框（手機上是底部面板），網址是 `/#guestbook`。
- 對話框上半部是留言表單：
  - 暱稱：1–20 字，會記在瀏覽器裡，下次不用重填。
  - 內容：1–300 字。
  - Cloudflare Turnstile 驗證（多數人不需要操作），以及「送出」按鈕。
- 下半部是留言列表，最新的在最上面，一次 20 則，底部有「載入更多」。每則留言顯示暱稱、相對時間（例如「3 天前」）、內容，以及一個「檢舉」按鈕。
- 內容裡的 `#數字`（例如 `#1234`）如果是存在的披風編號，會自動變成連結，點了直接打開那件披風（**使用者已確認**）。
  - 連結前面放這件披風的小圖：正面 10×16 像素，以 1 倍顯示，剛好跟一行字一樣高，維持像素銳利。圖直接從現有的圖集裁切，不多下載檔案。
  - 不存在的編號維持純文字；被合併的重複編號（alias）會連到它對應的那件。
  - 同一則留言最多轉換 5 個編號，避免被用來大量載入圖集。
- 送出成功後，留言立刻出現在列表最上面。失敗時顯示原因，例如「留言太頻繁，請 30 秒後再試」或「驗證失敗，請重試」。

## 防濫用

| 機制 | 規則 |
|---|---|
| Turnstile | 每次送出都必須通過，伺服器端驗證 token |
| 頻率限制 | 同一來源每 30 秒最多 1 則、每天最多 20 則 |
| 長度 | 暱稱 1–20 字、內容 1–300 字，超過就拒絕 |
| 內容過濾 | 含網址（`http`、`www.`、`.com` 等）的留言直接拒絕；另有一份可擴充的關鍵字清單 |
| 檢舉 | 累積 3 次檢舉的留言自動隱藏，等管理員決定 |
| 顯示 | 所有內容以純文字顯示，杜絕 XSS |

「同一來源」是用 IP 加上伺服器密鑰計算出的雜湊值來辨識，不儲存原始 IP。雜湊只用來做頻率限制和檢舉去重。

## 管理（第一版不做管理頁，使用者決定）

- 自動：被 3 個人檢舉的留言自動隱藏。
- 手動：在 Cloudflare 後台 → D1 → Console 用 SQL 隱藏或刪除留言，或請 Claude 透過 API 處理。常用的 SQL 寫在 `worker/README.md`。
- 代價：沒有管理介面，遇到大量洗版時處理較慢。之後可以再加上 `/admin`，並用 Cloudflare Access 保護。

## 技術做法

- **API**：現有的 Worker 加上 `/api/guestbook` 路由，其他路徑照舊回傳靜態檔案（`run_worker_first` 只套用在 `/api/*`）。
  - `GET /api/guestbook?before=<id>`：列表，一次 20 則
  - `POST /api/guestbook`：新增留言，需要 Turnstile token
  - `POST /api/guestbook/<id>/report`：檢舉
- **資料庫**：Cloudflare D1。
  - `messages`：id、nickname、body、created_at、ip_hash、hidden、report_count
  - `reports`：message_id、ip_hash，用唯一鍵防止同一人重複檢舉
- **前端**：新增 `src/ui/guestbook.ts`。對話框第一次打開時才抓資料、載入 Turnstile，首頁的負擔是 0。
- **測試**：
  - Worker 用 `@cloudflare/vitest-pool-workers` 搭配本機 D1 做整合測試
  - 前端用 jsdom 做單元測試
  - Playwright 端對端測試搭配假的 API 和 Turnstile 測試金鑰
- **費用**：Workers、D1、Turnstile 都在免費額度內。
